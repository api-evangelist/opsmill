# OpsMill — Infrahub

> OpsMill builds Infrahub, an open-source, graph-based infrastructure data
> management platform that serves as a unified source of truth for network,
> data center, and cloud automation. It combines an extensible schema, native
> version control (branching, merging, peer review, CI), and unified Git +
> graph-database storage, exposed through GraphQL, REST, a Python SDK, the
> infrahubctl CLI, a web UI, and an MCP server for AI agents.

## APIs

- [Infrahub GraphQL API](https://docs.infrahub.app/development-resources/graphql/overview): Primary interface, auto-generated from schema, branch-aware queries/mutations/subscriptions (`/graphql`).
- [Infrahub REST API](https://docs.infrahub.app/reference): Schema loading, artifact retrieval, object storage, auth, diff/file access (`/api`).
